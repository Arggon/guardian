# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x: |

## Reporting a vulnerability

<!-- Fill in a real contact. Do not report vulnerabilities through public GitHub issues. -->

- Contact: Gonzalo Arganaraz — **arggondev@gmail.com** (también disponible
  "Report a vulnerability" de GitHub en https://github.com/Arggon/guardian/security/advisories/new).
- Response target: acknowledge within 3 business days.
- Please include: affected version(s), reproduction steps, and impact assessment.

## Disclosure policy

Coordinated disclosure: se publica el detalle recién con la versión corregida
disponible (o 90 días después del reporte, lo que ocurra primero). `guardian` corre
en máquinas personales: un reporte puede implicar backups existentes afectados —
si el reporte involucra el formato del manifiesto o la verificación SHA-256, se
publicará junto con instrucciones de re-verificación de backups previos.
